# 天光 · 六城天气

> 六座城市的此刻天气与未来七天，含空气质量，只走 Open-Meteo 的免密钥公开接口。

[English](README.en.md) | 中文

## 这是什么

Open-Meteo 支持把多个经纬度用逗号拼在一起，所以六个城市一次请求就拿全：一个请求取实时与七天预报，另一个取空气质量，两个接口之间隔 1.1 秒，10 分钟一轮。不解析 HTML、不碰反爬、不需要密钥。数据落 SQLite 两张表——`readings` 存每次采样（保留 7 天），`forecast` 存七天预报，页面直接读内存里的缓存。单轮失败不清空页面，继续显示上一次成功的数据。

## 功能

- 一次请求取全部六城（接口支持经纬度逗号拼接）
- 每轮总共 2 个请求、10 分钟间隔，比刷一次网页还轻
- `readings` / `forecast` 两张表，采样保留 7 天
- AQI 用 US 口径分级，和国内 0–500 的阅读习惯接近
- 单轮失败保留上次成功数据，并在页面顶部说明
- 纯服务端渲染，无前端框架、无外部字体与图标

## 技术栈

Python 3.12 · Flask 3.1 · SQLite

## 运行

```bash
pip install -r requirements.txt
python app.py   # 默认端口 8840，可用 SKY_PORT 覆盖
```
